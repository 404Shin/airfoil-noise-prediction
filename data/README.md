# Dataset attribution

Brooks, T., Pope, D., & Marcolini, M. (1989). *Airfoil Self-Noise* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5VW2C

UCI lists this dataset under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). The raw data file is redistributed unchanged. Scaling is performed in memory using training data only.

Source: https://archive.ics.uci.edu/dataset/291/airfoil+self+noise

The dataset licence applies to the dataset; it does not establish a software licence for the repository's code.
